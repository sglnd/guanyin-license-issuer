# 签发系统安全边界

## 系统职责

签发系统负责验证授权申请、生成许可证声明、使用供应方私钥签名并记录签发审计。它不负责运行观因控制面，也不参与客户环境的在线验签。

## 信任关系

- `guanyin-license-issuer` 持有或调用签发私钥。
- `guanyin-enterprise` 只持有验签公钥。
- 客户环境提交企业名称、集群标识和当前授权信息，用于申请首发或续期 Token。
- 私钥与客户交付链路物理隔离。

## 实施前置决策

1. 冻结 Ed25519 Token 的规范、字段、规范化与序列化规则。
2. 确定生产私钥由 HSM、KMS 还是离线介质托管。
3. 定义双人审批、签发审计、密钥轮换和紧急吊销流程。
4. 定义测试密钥与生产密钥完全分离的机制。
5. 确定许可证申请文件和签发记录的保存、加密与删除策略。
