# 签发系统安全边界

## 系统职责

签发系统负责生成许可证声明并使用供应方私钥签名。客户授权审批与操作留痕由签发方流程负责；本 CLI 不负责运行观因控制面，也不参与客户环境的在线验签。

## 信任关系

- `guanyin-license-issuer` 持有或调用长期签发私钥。
- `guanyin-enterprise` 只持有 `public/guanyin-license-public.pub` 对应的固定验签公钥。
- 运营人员核对客户名称和授权期限后，在离线签发环境生成首发或续期 Token。
- 私钥与客户交付链路物理隔离。

## 当前实现边界

1. Token 使用 Ed25519 签名的紧凑 JWT，绑定完整客户名称和到期时间。
2. 当前提供离线 CLI，不提供在线签发服务和联网激活。
3. 测试每次运行时生成临时密钥，不保存或复用测试私钥。
4. 生产私钥的 HSM、KMS 或离线介质托管，以及双人审批、审计和轮换流程由签发环境另行落实。日常签发不会生成密钥对。
5. 密钥轮换需要明确批准，使用 `keygen --rotate yes` 生成替代密钥对，更新企业版固定公钥后重新签发所有仍有效的 License。
6. 第一版不支持在线吊销；需要提前终止授权时，按密钥轮换流程处理。
